# MVP 文档：VoiceTodo

版本：v0.1
日期：2026-08-12
状态：草案（与用户讨论后确定）

## 1. 一句话定位

一个免费的本地 iOS 语音待办应用：说一句话，自动转成文字并保存为一条可勾选的待办，待办自动出现在 App 内部日历中，列表与日历天然双向一致。

## 2. 目标与范围

### 目标
- 验证"语音 → 文字 → 待办 → 内部日历"的完整闭环在真实设备上可用、好用。
- 零服务端、零订阅、零账号，数据完全留在本机。
- 为后续"提醒功能、系统日历同步、云同步"预留扩展位。

### 明确不做（MVP 外）
- 不做智能提取/LLM 摘要。
- 不做系统日历同步（EventKit）。
- 不做云同步 / iCloud / 多设备。
- 不做语音实时转写（录完再转）。
- 不做账号体系、付费、广告。

## 3. 用户流程（核心路径）

```
打开 App → 长按/点击录音按钮 → 说话 → 停止
   → 转写中（本地 Speech） → 生成一条待办（音频 + 文字）
   → 待办出现在"待办列表"和"内部日历"两处
   → 打勾 → 变为已完成状态
   → 删除 → 两处同时消失
```

## 4. 功能清单与验收标准

### F1 录音
- 在录音界面按住或点击麦克风开始录音，再次点击停止。
- 录音过程显示时长。
- 验收：可录 10 秒～若干分钟的语音，生成音频文件，停止后立即进入转写状态。

### F2 语音转文字
- 使用 Apple Speech 框架（`SFSpeechRecognizer`，zh-CN）。
- 录音停止后自动转写，转写中显示进度状态。
- 转写失败（无权限/无网络/识别不了）时给出明确提示，且音频不丢失，可重试。
- 验收：安静环境下普通话口述一句，能转出正确文字；转写中 UI 有反馈；失败可重试。

### F3 待办列表
- 每条待办显示：转写文字、创建时间、已完成/未完成状态。
- 可点击勾选框切换完成状态。
- 可删除（列表左滑或详情删除），删除后内部日历同步移除。
- 未完成在前，已完成置灰排后。
- 验收：增、勾、删全部即时生效且持久化（重启 App 后数据仍在）。

### F4 内部日历
- App 内一个日历视图（月视图即可，可点选日期看当日待办）。
- 待办创建后自动出现在对应日期的格子上。
- 在日历中点击某个待办可查看详情，也可删除；删除后列表同步移除。
- 已完成待办在日历上以划线/变色显示。
- 验收：新建待办立刻出现在今天；日历里删一条，列表里也没了；反之一致。

### F5 详情与"⋯"菜单（含提醒入口）
- 点击待办进入详情页，可查看/编辑文字、播放录音。
- 每条待办提供"⋯"按钮，点击弹出菜单；该菜单为未来更多功能预留扩展位。
- MVP 菜单含"添加提醒"：点击进入提醒时间设置。
- 验收：能进详情、能编辑文字、能播放录音；"⋯"菜单弹出且"添加提醒"可用。

### F6 提醒（本地通知）
- 提醒默认无：新建待办不自动设提醒。
- 通过"⋯"→"添加提醒"设置提醒日期时间；已设置的可在同一入口修改或移除。
- 到点由系统本地通知提醒；待办完成或删除时自动取消对应通知。
- 验收：给待办设 1 分钟后的提醒 → 到点弹通知；打勾后不再触发；删除后不再触发。

### F7 数据持久化
- 本地 SwiftData 存储：文字、创建时间、完成状态、音频文件路径。
- 重启 App 数据完整保留。
- 验收：杀掉 App 重开，所有待办和状态还在。

## 5. 权限
- 麦克风权限（`NSMicrophoneUsageDescription`）。
- 语音识别权限（`NSSpeechRecognitionUsageDescription`）。
- 通知权限（`UNUserNotificationCenter`，用于提醒）。
- 首次使用引导授权，拒绝时给出解释和去设置开启的引导。

## 6. 技术要点（MVP 内）
- 语言/框架：Swift + SwiftUI，目标设备 iOS 26.6（工程最低版本 18.0，因 CI Xcode 限制）。
- 存储：SwiftData。
- 转写：`SFSpeechRecognizer` + `SFSpeechAudioBufferRecognitionRequest` 或文件识别请求。
- 录音：AVAudioRecorder 输出 m4a。
- 单一数据源：TodoItem 记录既是待办也是日历项，列表/日历共用同一数据模型，无同步逻辑。
- 服务层全部抽象成 protocol。

## 7. 交付与验证
- 产物：Xcode 工程，可在 iPhone（iOS 26.6）上构建运行。
- 分发：AltStore 免费自签。
- 验证路径：
  1. 真机授权三个权限；
  2. 录 30 秒普通话语音 → 出现正确文字待办；
  3. 日历今天出现该待办；
  4. 打勾 → 状态变化；删除 → 两处消失；
  5. 重启 → 数据仍在；
  6. 断网重试转写 → 失败提示合理、音频保留。

## 8. 里程碑

## 9. 风险
- Speech 中文准确率在口音/专业词场景下降 → 先接受，架构预留替换。
- 转写需要一段时间，长录音转写慢 → 用异步+进度提示。
- AltStore 需电脑配合续签 → 已在分发方案中明确。
