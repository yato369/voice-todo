# PRD 文档：VoiceTodo

版本：v0.1
日期：2026-08-12
状态：草案

## 1. 产品概述

### 1.1 一句话定位
一个免费的、本地优先的 iOS 语音待办应用。用户录一段语音，App 自动转成文字并存为一条可勾选的待办，待办自动同步进 App 内置日历，列表与日历天然双向一致。

### 1.2 目标用户
- 主要用户：本人（自用）。
- 适用人群特征：习惯说话记录、需要随手记待办、重视隐私和免费、不希望数据上云。

### 1.3 核心价值
- 说比打字快：语音一句话生成待办。
- 全免费、全本地、无账号、无订阅。
- 待办与日历一体化管理，删除任何一处两边同步。

## 2. 产品原则
- 本地优先：数据留在设备，不上传。
- 免费：无付费墙、无广告。
- 极简：录音 → 待办 → 日历，三步闭环，不加多余功能。
- 单一数据源：一条记录同时是待办和日历项。
- 可扩展：所有服务抽象成协议，未来可平滑接入提醒、系统日历、云同步。

## 3. 功能需求

### 3.1 录音
- 优先级：P0
- 描述：录制一段语音，作为待办的音频来源。
- 细节：
  - 录音界面有清晰的麦克风按钮和录音时长显示。
  - 停止录音后自动进入转写流程。
  - 录音质量：m4a（AAC），平衡体积与质量。
  - 音频文件保存在 App 沙盒 Documents/Recordings。
- 状态与边界：
  - 录音中退出 App 的处理：MVP 允许放弃或下次进入后继续（视实现难度）。
  - 录音失败提示。

### 3.2 语音转文字（Apple Speech）
- 优先级：P0
- 描述：使用系统 Speech 框架将语音转为文字。
- 细节：
  - 语言 zh-CN，可后续扩展到多语言。
  - 转写为异步过程，UI 显示"转写中…"。
  - 转写失败可重试，音频不丢失。
  - 权限被拒时引导去设置开启。
- 状态机：待转写 → 转写中 → 成功 / 失败。

### 3.3 待办管理
- 优先级：P0
- 描述：对转写生成的待办进行查看、勾选、编辑、删除。
- 细节：
  - 待办字段：id、文字、创建时间、完成状态、音频文件路径、提醒时间（预留）、日历标记。
  - 列表排序：未完成在前（按时间倒序），已完成置灰排后。
  - 勾选：点圆圈切换完成/未完成，即时保存。
  - 删除：左滑或详情删除；删除待办，日历中同步移除。
  - 编辑：详情页可修改文字。
  - 搜索：MVP 可选（P1），全文搜索文字。
- 验收：增删改勾全部即时生效并持久化。

### 3.4 内置日历
- 优先级：P0
- 描述：App 内日历视图展示待办，与列表同源。
- 细节：
  - 月视图为主，可按天查看当日待办。
  - 待办自动出现在对应日期。
  - 点击日历上的待办进入详情。
  - 日历中删除待办，列表同步移除。
  - 已完成待办以划线或弱色显示。
  - 点击空白日期可快速新增待办（可选 P1）。
- 同步实现：无独立同步层，因为列表和日历共用同一数据模型。

### 3.5 详情与"⋯"菜单（含提醒入口）
- 优先级：P0
- 描述：每条待办的扩展操作入口，为未来功能预留。
- 细节：
  - 入口：列表项或详情页的"⋯"按钮。
  - MVP 菜单项："添加提醒"，点击进入提醒时间设置；已设置的同一入口可修改/移除。
  - 菜单采用 ActionSheet / 底部弹窗。
  - 未来菜单项规划：导出、分享、转为普通备忘、关联重复等。

### 3.6 提醒（P0，MVP 内）
- 描述：给待办设置提醒时间，到点本地通知。
- 细节：
  - 提醒默认无：新建待办不自动设提醒。
  - 从"⋯"菜单进入"添加提醒"，选择日期时间 → 创建本地通知。
  - 待办完成或删除时自动取消对应通知。
- 依赖：本地通知权限 `UNUserNotificationCenter`。

### 3.7 系统日历同步（P2，暂不做）
- 描述：将待办写入系统日历（EventKit）。
- 细节：
  - 可选开关，默认关闭。
  - 同步为单向还是双向需进一步讨论。
- 状态：已确认 MVP 不包含，仅预留接口。

### 3.8 云同步（P3，暂不做）
- 描述：iCloud / CloudKit 多设备同步。
- 细节：
  - 通过替换 `StorageService` 实现，业务层无感。
- 状态：已确认 MVP 不包含。

## 4. 非功能需求
- 性能：启动 < 2 秒；列表滚动流畅；千条记录不卡顿。
- 隐私：本地存储，不上传；无第三方 SDK；不采集任何数据。
- 权限：最小化申请，首次使用时引导说明用途。
- 稳定性：转写中断、内存紧张、App 被杀等场景不丢数据。
- 兼容：最低 iOS 18.0（目标设备为 iOS 26.6；CI 云 Mac 的 Xcode 仅支持到 iOS 18.5 SDK，故工程最低版本定为 18.0）。

## 5. 技术架构

```
Views (SwiftUI)
  ├─ RecordView       录音界面
  ├─ TodoListView     待办列表
  ├─ CalendarView     内置日历
  └─ TodoDetailView   详情/编辑/⋯菜单

Services (protocol 隔离)
  ├─ SpeechTranscriber      Speech 框架转写
  ├─ AudioRecorder          录音
  ├─ StorageService         SwiftData 持久化 (protocol: StorageServiceProtocol)
  ├─ NotificationService    本地通知 (预留)
  └─ CalendarService        日历事件 (预留)

Models
  └─ TodoItem  (单一数据源：待办 + 日历项)
```

关键设计决策：
1. **单一数据源**：`TodoItem` 是待办也是日历项，杜绝双写不同步问题。
2. **协议隔离**：`StorageServiceProtocol`、`SpeechProtocol`，未来替换实现不污染业务。
3. **本地优先**：MVP 无网络依赖，转写也优先走设备端。

## 6. 数据模型（草案）

```
TodoItem
  id: UUID
  text: String                 // 转写文字
  audioFileName: String?       // 音频文件
  createdAt: Date
  isCompleted: Bool
  reminderDate: Date?          // 预留，提醒
  completedAt: Date?           // 预留
  calendarDate: Date           // 日历归属日期 = createdAt 或用户指定
```

## 7. 信息架构 / 导航

- Tab 结构：`待办` / `日历` / `设置`（设置 MVP 只含权限与关于）。
- 主入口：待办页底部或中心大按钮开始录音。
- 详情从列表或日历进入。

## 8. 发布与分发
- 目标平台：iPhone，最低 iOS 18.0（目标设备 iOS 26.6）。
- 分发方式：AltStore 免费自签（需要电脑 AltServer 每周自动续签）。
- 上架：暂不 App Store（如后续考虑，需开发者账号）。

## 10. 风险与对策
| 风险 | 对策 |
|---|---|
| Speech 中文准确率不足 | MVP 接受，协议化以便换云 ASR |
| 长录音转写慢 | 异步 + 进度反馈 |
| 本地数据误删 | 后续加"最近删除"回收站（P2） |
| AltStore 续签依赖电脑 | 自用场景可接受，文档说明 |
| iOS 版本碎片化 | 最低支持版本定为 18.0（受 CI Xcode 限制），目标设备 26.6 不受影响 |
